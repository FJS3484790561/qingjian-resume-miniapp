# 轻简履 · 青屿设计规范

状态：用户于 2026-10-21 选定 A 青屿；适用于 `src/pages/app/**`。基于已批准方案收敛，历史素笺/晴空保留为档案，不混入新页面。

## 业务与原则

面向求职者，在手机上分模块填写简历、整理经历、选择样式并检查全文。清新淡雅，以内容和主操作为核心；不采用强烈多巴胺色、装饰性大动画或虚构营销数据。首页轻盈、填写页聚焦、预览页文档优先。

实际使用 ui-ux-pro-max 搜索与设计系统能力，历史搜索依据保存在 `docs/design-proposals.md`；补充 error summary validation、cancel progress retry 与 Vue 表单建议。库建议需经过业务和微信平台筛选，不直接覆盖用户选定风格。

使用语义 CSS 变量；文档主题色与应用主题分离。错误/成功同时配文字，不只依赖颜色。当前仅批准浅色主题，不宣称完成深色适配。

系统中文无衬线：PingFang SC / Microsoft YaHei；少量文档/英文采用系统衬线。字号：正文 28rpx，表单 29rpx，辅助 24–26rpx，小标签 21–23rpx，大标题 47rpx，次级标题 36rpx；行高 1.5–1.9。缩略图小字只用于示意，全文有放大阅读入口。

间距采用 4/8px 节奏，页面左右 40rpx；卡片内边距 24–28rpx；段间 24–36rpx。卡片圆角 28rpx，大区块 40rpx，输入/标签 12–20rpx，1px 边框；轻阴影 `0 8rpx 30rpx rgba(37,67,47,.025)`。

## 统一组件

- AppFrame：实际微信胶囊、状态栏、返回/标题、滚动内容、底部安全区；正文与固定按钮区域分开布局。底栏使用明确的 q-footer-row 横排和 q-footer-primary 伸展区，避免小程序插槽宿主打断布局。导航按真实胶囊位置预留宽度并响应尺寸变化。
- ActionButton：一个主要任务，最小 50px 高；加载时禁用，反馈不改变周围布局。
- AppIcon：统一线型图标族，装饰图标隐藏语义；独立操作给清晰名称，触摸区至少 44px。
- 输入：可见标签、选填提示、字数、行内错误；保存失败保留输入，多错误同时有汇总。
- RichField：加粗/斜体/下划线/两种列表；初始化完成后才能编辑，内容最多 10000 字。
- 选择器：原生月份/日期/多列薪资/单选，支持取消和清空；时间范围非法时提示。
- 卡片：明确标题与摘要，长内容省略仅用于列表；全文预览保留完整内容。
- 弹层：Wot Popup，z-index 100，高于导航/底栏；可关闭，危险操作二次确认，处理期间阻止重复。
- 反馈：空状态提供下一步，错误可重试，成功说明实际结果。会员未勾选时滚到说明和错误区域，避免屏外反馈；AI 重新整理/切换目标先确认放弃未应用结果。模拟流程必须标明“模拟/本机”，不冒充支付、AI 或导出成功。

## 页面与内容

首页以开始制作作为唯一核心入口，模板/照片/WORD 为并列工具，当前草稿支持继续。模板使用两列、分类/搜索/选中反馈。填写按模块聚焦，多段经历先列表后编辑。预览展示实际数据，内容顺序遵循模块管理；文档有放大、封面、主题与排版入口。

本轮 6 款模板是代码排版示例，3 种结构；不复制竞品图片。人物/学校/经历为虚构数据。前端估算分页需保证不丢文字，最终 A4 排版和 PDF 由后续文件服务单独验收。

适配 375px 小屏与较大手机，导航预留胶囊，固定操作考虑底部安全区，输入启用键盘位置调整。横屏、大字体、原生键盘仍以实际设备检查为准。

## 动效与中断

| 触发 | 变化/时长 | 结束/中断 |
|---|---|---|
| 按压按钮 | 透明度约 120ms | 释放恢复，加载禁用 |
| 打开设置 | 底部面板进入，约 220ms | 停在选项；关闭保留已即时保存设置 |
| 生成预览 | 按钮 loading，约 350ms | 打开预览；离页清除过期跳转 |
| 模拟会员/AI | 约 600–650ms loading | 成功或错误；离页取消，原文保留 |
| 模拟下载 | 每 140ms 更新进度 | 完成记录一次；取消/离页不记录 |
| 照片生成 | 真实 canvas 回调 | 显示本机 PNG；调整取景或离页使旧结果失效 |

减少动态开关及系统 prefers-reduced-motion 将自定义过渡设为 0ms，保留必要状态文字与加载锁。不引入 GSAP 等网页专用动效；第三方弹层/原生页面动效仍需在微信端检查。

## 账号与备份页补充（2026-10-24）

沿用已有青屿变量、AppFrame/ActionButton 和卡片；不重新生成视觉方案。账号与服务连接、当前草稿备份、服务端列表分段；开发身份/实际微信身份文字区分。备份入口写明主动上传文字、排版和已选照片，按账号私有保存；导入说明新建草稿与离页取消，成功/冲突/网络错误均有持久文字。按钮不低于 48px，处理中禁用，删除二次确认。

本轮 ui-ux-pro-max 的 Vue `async loading error retry` 搜索 0 匹配，改用 ux `loading feedback` 后命中 Loading Indicators / Loading States 等 3 条，采纳加载状态、稳定布局和清晰反馈；没有把未命中的搜索当作结果或覆盖已批准 MASTER。

## 真实文件与照片交互补充（2026-10-24）

备份按钮明确包含主动选择的照片；页面说明账号私有存储和离页结果。下载默认进入真实服务：格式选择、准备、排队、生成、完成、取消、失败各有文字反馈，生成中禁止重复请求。使用实际服务状态，不展示虚构百分比；进行中离页继续在后台，完成后用户主动下载/打开。取消使旧轮询失效；换账号或草稿不展示旧任务结果。下载记录区分真实账号文件和本机模拟记录，删除二次确认。

沿用 AppFrame、ActionButton 与语义变量。按钮不低于 44px，格式项同时用边框、底色和文字区分；减少动态保留必要状态信息，不新增动画库。ui-ux-pro-max `async job cancellation feedback` 命中 Loading States / Loading Buttons，采纳显式加载反馈、防重复点击；没有改动已批准的配色/字体方向。


## AI 服务入口补充（2026-10-25）

保留青屿变量和已有 AppFrame/ActionButton；AI 优化/本机演示并列切换，禁止只靠颜色区分，加载和应用后锁切换。服务卡显示“已配置/待配置”、服务商/模型、刷新和账号入口；“已配置”不能冒充上游已成功连接。正文展示后才提供明确的传送同意，未配置/未登录/未同意时主按钮禁用。

加载显示提交/排队/优化实际状态及取消，不造百分比；结果标注 AI 建议或本机示例，可手改、保留、应用、撤销。取消及离页不声称保证未计费。错误保留原文并提供可用重试，账号/草稿改变清除旧视图。ui-ux-pro-max `async cancellation retry` 命中 Loading States / Loading Buttons / Contextual Live Badge Updates；采用加载反馈、禁止重复提交、完整状态文案，未改选定视觉方向。
