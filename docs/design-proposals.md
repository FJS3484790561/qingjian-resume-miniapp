# 三套候选视觉方案

更新日期：2026-10-21。**候选方案，等待用户选择；尚未成为全项目正式设计规范。**

## 项目理解与假设

用户要制作个人简历微信小程序，以对标产品功能为依据，UI 重新设计。核心任务为填写经历 → 生成预览 → 挑选文档样式 → 下载。现阶段优先照顾学生、初入职场及希望快速整理简历的个人用户，这是设计假设，并非已确认的人群限制。

原型三套都覆盖首页、内容丰富的模板列表和简历编辑，并额外串联预览。使用同一份明确标注为示例的虚构简历（林知夏、产品设计师、杭州、示例学校/项目、example.com邮箱），共 6 款原创代码排版缩略图。分类筛选属于候选设计建议，非对标已验证需求。

用户指定整体“清新淡雅”。通用要求中的“多巴胺”按愉悦反馈和辨识度理解，不把大面积高饱和色当作主风格。沿用对标的功能入口与内容类型，不复制其火箭背景、商业模板图片或品牌素材。

## ui-ux-pro-max 的实际使用

运行 `scripts/search.py` 的三次 `--design-system`：`resume builder calm minimal`、`resume editorial elegant`、`productivity workspace soft`。前两次返回 Minimalism & Swiss Style，第三次返回 Flat Design。两次简历检索附带的字体配对偏向地产行业，营销视频首页模式也不适合工具型小程序，因此没有直接采用这些部分。

随后用明确 domain 重试：

- `soft minimal --domain style` → Minimalism & Swiss Style：采用空间、秩序、清晰层级与低装饰开销。
- `editorial typography --domain style` → Editorial Grid / Magazine：只借鉴纸张编排、细分隔线、标题与正文层级；不用多列长文、视差或翻页重动画。
- `bento cards --domain style` → Bento Box Grid：借鉴任务卡片、不同尺寸信息块及轻量工作台。
- `Chinese readable --domain typography` → Chinese Simplified / Noto Sans SC：采用中文可读性建议，以系统中文黑体栈为主，不依赖外部字体下载；B 的标题辅以本机宋体字体栈。
- `form validation feedback --domain ux` → 提交反馈、可见标签、行内校验。
- `forms state components --stack vue` → Vue 组件与状态建议。原型仅少量共享数据，使用项目组件和本机存储，不为演示额外引入重状态框架；跨端表单保留平台原生输入组件。

以上为已核实命中的建议。各方向颜色、中文文案、业务布局与编辑方式均为结合简历场景的设计判断，而不是数据库直接提供的成品。

## A · 青屿（推荐）

- 鼠尾草绿、灰白底、适度圆角、留白与轻量文档插画。
- 首页以制作入口、辅助工具、最近草稿形成清晰顺序；模板为双列缩略图。
- 编辑以模块卡片为单位，点开底部表单。保存整段内容后返回模块列表，取消时丢弃本次弹层内未保存编辑。
- 优点：亲和、认知负担低，最适合快速制作；取舍：单位屏幕的信息容量低于 B。

## B · 素笺

- 暖白纸张、宋体标题、细线、编号、小圆角；避免圆润卡片堆叠。
- 首页为编辑部式纵向编排；模板采用单列图文条目，更容易阅读差异描述。
- 编辑呈连续文档表单，可一边向下读、一边整理内容。
- 优点：个人表达与作品感强，适合内容认真打磨；取舍：长表单需要更多滚动，系统宋体实际显示随设备变化。

## C · 晴空

- 雾蓝、浅灰白与少量暖色，较紧凑的工作台和任务型卡片。
- 首页强调“继续完善”与进度；模板在白色容器内分组，明确选中标识。
- 编辑分为认识你 / 看见积累 / 下一程三步，可回退、跨步，最终生成预览。
- 优点：目标与步骤清楚；取舍：熟练用户跨步编辑多一次点击。进度仅表示示例已填模块，不是系统评分。

## 候选交互规范

| 动作 | 反馈 | 结束状态 | 连点、取消、中断 |
| --- | --- | --- | --- |
| 触摸按钮/卡片 | 120ms 透明度/颜色变化，不移动周围布局 | 返回静态 | 保持触摸区域稳定 |
| 选择模板 | 选中边框、文字勾选、底部样式名同步 | 保留当前选择 | 后一次选择覆盖前一次 |
| A 打开模块 | Wot底部弹层，220ms | 光标未被强行激活 | 取消不合并缓冲表单；保存时禁用重复操作 |
| 草稿保存 | 按钮加载约650ms，成功提示；存储异常保留内容并给出重试提示 | 仅保存本机原型命名空间 | 单次操作锁；导航取消过期回调 |
| 生成预览 | 按钮加载约800ms，进入当前数据排版预览 | 显示示例文档 | 连点忽略，离页不触发过期跳转 |
| 联系方式格式错误 | 对应字段下方持续显示具体错误，保留输入 | 等待修改 | 不清空用户内容 |
| 姓名为空 | 提示可能不完整，可返回补充或仍要预览 | 由用户选择 | 不把帮助文案误变为强制拦截 |

支持减少动态：审阅页开关及系统 `prefers-reduced-motion`。使用平台支持的 view/text/input/textarea/scroll-view、CSS 过渡及 Wot 组件，不用 DOM 操作、网页专用动画或大型视觉素材。微信端预留状态栏/胶囊及底部安全区；浏览器胶囊为模拟占位。

## 阶段边界

不接生产服务，不登录，不调用AI、不上传照片、不付款。WORD/证件照/更多模块和真实导出保留入口并如实说明本轮范围。原型里“保存”仅写本机隔离草稿；生成只更新本地文档预览。未实现的完整业务不以提示“成功”冒充完成。

选定后再收敛唯一 MASTER 规范、完善统一组件，并扩展全部页面。当前三个 token 集只是候选，不能混用成正式设计系统。
