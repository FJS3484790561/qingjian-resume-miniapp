# 青屿前端测试清单

版本 0.2.0，2026-10-21。请在微信开发者工具导入 `dist/build/mp-weixin`，AppID 为 `wxdccead0ec32190d0`。这是供逐项测试的纯前端版本，不代表所有项均已验收。

## 开始与反馈

首页或“我的”底部 → 前端测试台。可创建空白/示例/长内容简历，切换正常完成、服务错误、下载额度用完。模拟会员已开通后额度场景会放行；如要重新检查未开通状态，可在设置中清空本机体验数据（会丢失本机草稿，请先保留所需内容）。

建议使用虚构内容。问题反馈格式：页面 → 操作步骤 → 预期 → 实际 → 截图。注明微信开发者工具/手机型号，以及模拟状态。

## 草稿与信息填写

- [ ] 新建空白、新建示例、切换草稿；不同草稿内容/排版独立。
- [ ] 基本信息姓名入口正常，21 个字段及证件照可编辑、清空、保存、回填。
- [ ] 错误邮箱/电话/超长内容就近提示，保存时输入不丢失；改正后可保存。
- [ ] 性别、婚姻、政治面貌、月份、学历等选择器可选择/取消/清空。
- [ ] 求职意向 4 字段；职位/地点 15 字上限；薪资左右范围非法时提示。
- [ ] 教育、在校、实习、工作、项目：空列表 → 新增 → 保存 → 编辑 → 再新增多条。
- [ ] 开始/结束日期、至今、结束早于开始、时间正倒序符合预期。
- [ ] 富文本初始化不丢原文；斜体/加粗/下划线/有序与无序列表，保存后再次编辑保留格式。
- [ ] 技能/证书/爱好各 15 项，自评、报考 5 科、自荐信、4 个自定义模块均可保存回填。
- [ ] 自定义模块改名，未保存返回出现提醒，继续编辑/放弃各自结果正确。
- [ ] 删除/清空先确认；取消保留数据，确认只影响当前模块/当前草稿。
- [ ] 退出/重新编译后本机内容可恢复；没有 null/undefined；重复点击不重复创建记录。

## 模拟下载、会员与 AI

- [ ] 下载正常：进度 → 模拟成功 → 仅一次记录；不出现伪造文件路径。
- [ ] 下载取消/返回时不新增记录；快速连续点击无重复。
- [ ] 服务错误：显示错误和重试，草稿保留；额度用完：说明、倒计时、会员入口正常。
- [ ] WORD 列表/详情 → 下载模拟，与简历下载说明区分。
- [ ] 会员：4 套餐、未勾选提示、取消确认、正常完成、错误与重试；不扣款。
- [ ] AI：无内容提示、选择正文、加载、错误重试、编辑结果、保留原文、应用和撤销。
- [ ] 处理中返回/离页后，不延迟跳页、不覆盖其他模块、不出现过期成功。

真实账号、云同步、支付/会员结算、AI、PDF/DOCX 导出和分享等待后端阶段，不以模拟完成代替实际服务验收。
