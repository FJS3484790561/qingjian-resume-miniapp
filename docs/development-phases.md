## 第三阶段验收步骤

本轮完善照片与所有辅助模拟流程，并增加取消、异步竞争及保存故障回归。自动检查和实际操作见 [validation.md](validation.md)；以下复选框留给用户记录，不因开发完成自动勾选。

- [ ] 测试台新建独立示例 → 证件照选择任一规格 → 调取景和底色 → 生成 → 应用 → 回到简历与预览看到照片；再次应用不重复处理。
- [ ] 自行操作选图/相册权限；取消保留原照片和取景，拒绝有说明可重试；六规格 PNG 像素正确。原图背景不会被抠掉。
- [ ] 正常下载只新增一条模拟记录；WORD 列表/详情进入的下载返回对应模板；当前不生成 PDF/DOCX。
- [ ] 下载开始后取消/返回，不延迟新增记录；测试台切服务错误，再测下载、AI、会员，原文和原模拟权益保留。
- [ ] 测试台点“重置模拟会员（保留简历）”并选额度用完 → 下载 → 说明/倒计时 → 会员；无需清空任何草稿。
- [ ] 会员未勾选有提示；选套餐、勾选、确认/取消和正常模拟完成符合预期，不扣款。
- [ ] AI 结果手动修改、重新整理/切换内容时取消应保留编辑；应用后原模块更新，撤销恢复原文；未应用返回可继续编辑或放弃。
